## 1. 等价性定义（论文的核心命题）

迁移达成**任务等价**：相同机器人、物体、初始语义状态、语言指令、7D OSC 动作接口（20Hz）、观测 schema、BDDL 成功条件；不追求逐帧轨迹等价（接触求解器/积分器不同，文献实测跨仿真回放成功率 15~70%）。「同样效果」操作化为四层可测指标：

1. **状态层**：同 init state + 同动作序列下，EE 位姿 per-step 误差（mm/deg）随时间曲线；关键物体终局位姿误差。
2. **谓词层**：逐帧 BDDL 谓词判决一致率；终局成功/失败判决一致率 + Cohen's κ。
3. **任务层**：开环回放双 sim 成功率；闭环（VLA checkpoint）双 sim 成功率差。
4. **正式性层**：物理参数审计清单通过率；dt 减半收敛性测试（结果漂移 < 阈值）。

## 2. 总体架构

```
LIBERO 官方仓（pip 依赖：.bddl / .pruned_init / assets / HDF5 demos）
        │  setup 时一次性（独立 MuJoCo 环境，我们的 converters）
        ▼
task_manifest.json + init_states_50.json + USD 缓存   ← 语义层（位姿按名索引、旋转存 3×3 矩阵、显式 convention）
        │
┌───────▼─────────────────────────────────────────────┐
│ libero_isaac_sim（Isaac Lab ManagerBasedRLEnvCfg）   │
│  自研 BDDL 解析 │ 场景构建 │ 7D OSC 动作适配 │ 观测适配 │
│  reset 转换器（settle 后计步）│ 张量化谓词 │ 评测 harness │
└───────┬──────────────────┬──────────────────┬───────┘
        │                  │                  │
   VLA facade         RL 并行基准          teleop/Mimic
        └──────────────────┴──────────────────┘
                           ▼
              Isaac Sim 6.1 + PhysX + RTX

等价性验证层（长期保留 MuJoCo 基准侧）：
paired_rollout harness：Isaac 主进程 ↔ MuJoCo 子进程锁步步进
（同 init_state_id、同动作序列、逐步交换语义状态与谓词判决）
        ▼
指标计算 + 双机位同步渲染 → side-by-side 动画/关键帧对比图
```

## 3. 双环境策略

- **isaac 环境**：py3.12 + uv，Isaac Sim 6.1 + Isaac Lab v3.0.0-EA（pin），openpi/OpenVLA-OFT 单独子环境经 server-client 接入；
- **libero-mujoco 环境**：py3.11 + conda/uv，robosuite + mujoco==3.3.1（GR00T 仓实测兼容组合），LIBERO 官方仓可编辑安装；整个项目周期保留（对比实验与动画都依赖它）；
- 两环境通过 paired_rollout 桥通信（子进程 + npz/zmq 消息），锁步交换：动作、EE 位姿、各物体位姿、关节角、谓词判决；
- sudo（511213）用于显卡驱动/EGL/Vulkan 等渲染依赖安装。

## 5. 分阶段实施（goal mode 迭代，每阶段 git commit，里程碑打 tag）

- **Phase 0 环境**：GPU/驱动检查（sudo 装依赖）；isaac 环境冒烟（headless Franka spawn + 相机渲染）；mujoco 环境冒烟（LIBERO 任务 0 reset/step）；paired_rollout 桥原型。
- **Phase 1 导出管线**：converters 三模块；任务 0 资产（living_room_table、basket、alphabet_soup、tomato_sauce）转 USD + 校验报告；导出 manifest + 50 组 init states（旋转矩阵格式）。
- **Phase 2 核心框架**：bddl_parser/regions/predicates、LiberoActionAdapter（单轴探针双 sim 方向单元测试先行）、observations/cameras、events/terminations。
- **Phase 3 试点端到端**：任务 0 gym 注册、eval harness 跑通；验证阶梯 L0–L8 全过；teleop 冒烟。
- **Phase 4 等价性实验 v1**：paired_rollout 跑任务 0 全部 50 demo 动作序列；动作幅值标定；输出四层指标；渲染一致成功/一致失败案例的 side-by-side 动画与关键帧图。
- **Phase 5 关节体攻坚**：任务 9 microwave 转 ArticulationCfg（人工核对 hinge 轴/限位/碰撞）；Open/Close/In 谓词；L5 验证；microwave 等价性实验。
- **Phase 6 泛化剩余 8 任务**：按场景族批量迁移；每任务过验证阶梯 + 回放一致性 smoke 门槛；沉淀「不变层 vs by-case 层」清单（文章素材）。
- **Phase 7 闭环实验**：OpenVLA-OFT LIBERO-10 checkpoint 双 sim 闭环成功率对比（20 eps × 任务）；脚本化 oracle 策略闭环作为对照组。
- **Phase 8 物理正式性**：资产审计清单（惯性/摩擦/碰撞网格/关节阻尼限位）；不合理参数修正 + 偏差文档化；dt 收敛性测试。
- **Phase 9 发表包**：按论文结构写作（摘要/引言：迁移意义/方法：不变与变+系统设计/实现：代码细节无遗漏/实验：指标体系+表格+图+渲染对比穿插/结论）；产出自包含 HTML + 知乎 markdown + figures/；文字风格：教科书式中文、直接陈述、无套话。
- **Phase 10 收尾**：git 历史按功能整理、README 复现指南、全部测试绿灯。

## 6. 验证阶梯（每任务必过）

L0 场景几何 → L1 reset 语义状态 → L2 FK/EE 系 → L3 动作方向/幅值（1/5/10 步探针）→ L4 夹爪 → L5 关节体 → L6 接触/摩擦 → L7 相机 → L8 谓词 → L9 VLA checkpoint zero-shot rollout（冒烟性质）。
